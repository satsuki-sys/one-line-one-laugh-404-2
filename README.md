Entry for the [One Line, One Laugh](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3) competition on make.fun.

## What it does

`main.py` (Python 3.13, standard library only) writes one original funny line to `/output/entry.txt`:

> I taught my dog to fetch my slippers. Now he brings the neighbour's slippers, the neighbour's mail, and — yesterday — the neighbour.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
